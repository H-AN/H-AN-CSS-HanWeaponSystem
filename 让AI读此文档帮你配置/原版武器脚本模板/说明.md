# CSS 武器脚本模板库

本目录附带作者提供的 29 份 CSS 原版武器 TXT 脚本副本，AI 可直接读取 [scripts/weapon_ak47.txt](scripts/weapon_ak47.txt) 等完整文件，复制并生成新武器脚本，不依赖作者电脑的绝对路径。

来源记录：`D:\css\移动\css武器原版脚本\css_weapons_txt_1592011\cstrike\scripts`，于 2026-10-29 复制。这里只记录提供者目录，未据目录名称推断它与所有 CS:S 版本完全一致；脚本保留原内容，仍需核对用户模板、游戏版本和实际行为。[SHA256SUMS.txt](SHA256SUMS.txt) 记录各副本的 SHA-256，便于确认模板未被修改。

已核对 29 份副本与来源文件的哈希，并按不启用反斜杠转义的 KeyValues 规则检查根节点和嵌套键值结构；未作目标游戏版本内的运行测试。特别是 C4 字体的单反斜杠字符，不应拿 JSON/C 字符串的转义规则强行改写。

## AI 必须执行的复制规则

1. 先确认主武器/副武器/刀/手雷以及弹药机制，再选具体模板。不能仅因为模型叫 AK47 就替用户决定使用 AK47 行为。
2. `classname "weapon_ak47"` 通常以本库 `weapon_ak47.txt` 为起点；输出必须改成 `scripts/<新的 useclassname>.txt`。库内模板和服务器原版脚本都不直接修改。
3. 保留完整 `WeaponData` 结构、声音/纹理等子节点和模板所需字段。只按确认需求改模型路径、弹匣容量、弹药机制、基础数值等；不要从零省略大部分字段。
4. 用户要求几发弹匣，改新脚本 `clip_size`；主配置 `ammo` 是发放弹药/补备弹用途，不能当弹匣容量。
5. 无弹匣可见原刀/手雷模板的 `clip_size "-1"`。刀的 `primary_ammo/secondary_ammo` 为 `None`；手雷主弹药仍为 HE/闪光/烟雾对应类型。无弹匣和无消耗不是同一个概念，不能把 `clip_size` 或 `default_clip` 填成 `None`。
6. 右键、消音器、全自动、分段换弹、特殊无弹药攻击等行为结合模板和现有插件判断，不能随意改 `WeaponType`、`bucket` 或某一个字段就承诺改变整个实体机制。
7. 所有输出脚本与 HanWeaponData.cfg、子配置、独立模型目录和下载表使用一致的新路径。模板中的原版声音/纹理引用若继续使用，确认游戏能够解析；自定义资源改名则同步更新相关引用。
8. 不把模板库整目录当成服务器安装包，不能把 29 份原版脚本全部覆盖到 `cstrike/scripts/`。

仅拿到一份 Markdown 文档而没有这些 TXT 时，AI 无法读取本库。请用户提供本模板目录或完整文档包，不把来源路径当成已附带的文件内容。
